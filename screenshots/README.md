# Screenshots

Place your screenshots in this directory with the following names:

## Required:
- `dark-mode.png` - Widget in dark mode (collapsed)
- `light-mode.png` - Widget in light mode (collapsed)
- `expanded-openai.png` - OpenAI section expanded
- `expanded-model-group.png` - A model group expanded
- `full-expanded.png` - Everything expanded

## Optional:
- `demo.gif` - Animated demo (use tools like Kap or Gifski)
- `drag-demo.gif` - Showing drag functionality
- `theme-toggle.gif` - Showing theme switch

## Screenshot Guidelines:
1. Clean desktop background
2. Widget clearly visible
3. 2x retina resolution preferred
4. PNG format for static images
5. GIF format for animations (keep under 5MB)

## Tools for GIF Recording:
- [Kap](https://getkap.co/) - Free, open source
- [Gifski](https://gif.ski/) - Convert videos to GIFs
- macOS QuickTime + Gifski workflow
